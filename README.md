# AI H5 Editor

面向营销场景的可视化 H5 搭建工具：拖拽或对话生成页面，按设计规范校验，一键预览、发布，也能导出 Vue 代码。

**无需登录，打开即用。** 页面和上传的图片都保存在你的浏览器里，不依赖后端；想用大模型生成页面时，在「设置」里填自己的模型 Key 即可。

## 能做什么

- **搭建页面**：拖拽组件、多页面管理、手机 / 平板预览、撤销重做、自动保存。内置优惠券、商品推荐、秒杀、拼团、抽奖、倒计时、营销表单等组件。
- **AI 对话生成**：描述需求就能生成多页面，也可以框选组件后说怎么改。按 `Cmd/Ctrl + K` 随时发起。
- **规范与风格库**：基于 Ant Design Token 校验颜色、间距、圆角、字号；扫描项目生成「风格库」差异，逐项采纳后发布版本。
- **设计转代码**：把页面导出为 Vue 单文件组件、CSS 或 Design DSL。
- **预览与发布**：二维码预览、发布路径与访问密码、发布检查。
- **素材与模板**：模板中心、作品管理、本地素材库。

各功能的详细说明见 [功能说明](docs/features.md)。

## 快速开始

需要 Node.js 18+ 和 [pnpm](https://pnpm.io)。

```bash
pnpm install
pnpm dev        # 本地开发
pnpm build      # 构建
pnpm preview    # 预览构建结果
```

## 数据与隐私

- 页面保存在浏览器 localStorage，上传的图片保存在 IndexedDB，不会上传到任何服务器。
- 换浏览器或备份：「设置」里可导出 / 导入项目文件（含上传的图片）。
- 示例图支持外链和本地两种来源，在「设置」中切换；外链加载失败时自动改用本地示例图。
- 模型 Key 只保存在本机浏览器。不配置时使用内置的本地规划器，不联网。
