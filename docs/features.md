# 功能说明

## 页面与路由

顶部导航固定为：工作台 / 模板中心 / 我的作品 / 素材管理 / 风格库 / 设计转代码。

| 路径 | 页面 | 说明 |
| --- | --- | --- |
| `/workspace` | 工作台 | 最近作品、新建空白项目、从模板创建、状态概览 |
| `/templates` | 模板中心 | 分类筛选、搜索、收藏、自定义模板、预览并一键应用 |
| `/projects` | 我的作品 | 全部 / 已发布 / 草稿 / 回收站，搜索、编辑、复制、删除 |
| `/assets` | 素材管理 | 图片、图标、插画等分类；上传的图片保存在本机，可一键添加到页面 |
| `/` | H5 编辑器 | 见下文 |
| `/styles` | 风格库 | 二次蒸馏、采纳 / 驳回、发布版本 |
| `/handoff` | 设计转代码 | 生成 Vue / CSS / DSL，真机扫码走查 |
| `/preview` | 独立预览 | 手机浏览器打开的预览页 |

## H5 编辑器

- 组件拖拽或点击添加；左侧为组件库、页面管理、模板、素材、图标和 AI 对话。
- **无限画布**：所有页面并排摆在同一块画布上，当前页可直接编辑，其他页点击即切换。滚轮平移，`Ctrl/⌘ + 滚轮`以光标为中心缩放（10%–400%），空格或拖动空白处移动画布；`Shift+1` 适应全部页面、`Shift+2` 定位当前页、`Shift+0` 回到 100%。标尺刻度随缩放自适应。拖动画框上方的页面名称可以移动页面，会吸附到其他页面的边和中线并显示对齐线，位置随项目保存；左下角「整理页面」恢复横向排列。
- 多页面：切换、复制、排序、重命名、删除。
- 手机 / 平板预览，Hover / 选中状态，选中后可上移、下移、删除。
- 右侧属性面板：内容、样式、交互、动画。
- 撤销 / 重做、自动保存。
- 营销组件：优惠券、商品推荐、营销表单、秒杀、拼团、抽奖、倒计时、轮播、图片、按钮等。部分组件在预览态支持交互，如领取、加购、报名、参团和抽奖反馈。

## AI 对话与 Agent

- 描述需求即可生成多个页面；先在画布上点选或使用「框选改图」选中组件，再说怎么改。
- 支持多会话，以及「规范优先 / Prompt 优先」两种模式：规范优先时，偏离规范的要求会记入「偏离清单」。
- 快速发起：任意页面按 `Cmd/Ctrl + K`，生成期间顶部显示任务悬浮岛，点击回到对应会话。
- Agent 只产出结构化补丁（新建页面、追加 / 修改 / 删除组件），一次生成合并为一条撤销记录。
- 默认使用本地关键词规划器，不联网；在「设置」填写 OpenAI 兼容的模型接口和 Key 后改用大模型，调用失败时自动回落到本地规划器。

## 规范与风格库

- 设计规范基于 Ant Design Token，页面样式里可以写 `{color.primary}` 这样的 Token 引用，预览时解析为 CSS 变量，导出 HTML 时解析为具体值。
- 规范校验检查颜色、4px 间距栅格、圆角与字号刻度，AI 面板底部可查看并一键修正。
- 风格库：内置 Ant Design，可新建自己的风格库。「二次蒸馏」会扫描项目所有页面里未登记的颜色 / 圆角 / 字号，逐项采纳或驳回，全部确认后发布新版本（如 v5.0 → v5.1）；采纳的取值此后不再算偏离。

## 设计转代码

在 `/handoff` 选择页面，生成 Vue 单文件组件、CSS 和 Design DSL，可复制或下载，Token 在 CSS 中保留为 `var(--ud-*)`。走查清单显示偏离数、硬编码颜色数与 Token 引用数。小页面可扫码在手机上走查；页面太大时二维码装不下，改用「在新窗口预览」。

## 预览与发布

手机 / 平板预览、二维码预览、发布路径配置、公开 / 密码访问、发布检查、发布成功页和链接复制。

## 当前范围

- 不包含：数据分析、团队协作、账号与登录、服务端存储。
- 暂未做：图层树、多选对齐、画布内直接改文字、MCP 服务（需要后端）、会话分支。
- 新增页面或复杂交互遵循「先设计、后开发」，统一使用项目 Design Token（见 [设计系统](design-system.md)）。
