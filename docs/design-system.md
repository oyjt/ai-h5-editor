# AI H5 Editor 设计系统

> 本文档是后续 UI 开发和交互实现的统一约束。新增页面、组件、弹层和状态时，应优先复用这里的视觉 token 和交互规范，避免单页面自行定义风格。

## 1. 设计定位

产品定位为桌面端 H5 营销可视化搭建平台。整体风格遵循：轻量、清晰、专业、弱装饰、强层级、蓝色品牌强调、白色卡片与浅灰工作区。

设计稿还原优先级：

1. 结构与信息层级
2. 尺寸与间距
3. 字体与色彩
4. Hover / Selected / Disabled / Loading 等状态
5. 阴影、圆角、描边等细节
6. 响应式降级策略

若设计稿没有覆盖某个新页面或复杂交互，应先补设计稿，再开发。

## 2. 设计 Token

代码统一维护在 `src/styles/design-system.css`。

### 品牌色

- 主品牌色：`--brand-600: #1769ff`
- Hover / 浅背景：`--brand-50` ~ `--brand-200`
- 选中描边：`--border-brand: #73a8ff`
- 危险态：`--danger-500: #ef4444`
- 成功态：`--success-500: #22a06b`

不要在新组件中随意新增接近但不同的蓝色。若必须扩展，先补到 Token。

### 表面与边框

- 页面工作区：`--surface-0`
- 一级卡片 / 面板：`--surface-1`
- 次级浅背景：`--surface-2`
- 轻填充：`--fill-soft`
- Hover 填充：`--fill-hover`
- 轻边框：`--border-subtle`
- 常规边框：`--border-default`

### 文本

- 强标题：`--text-strong`
- 正文：`--text-primary`
- 辅助文字：`--text-secondary`
- 弱提示：`--text-muted`
- 禁用：`--text-disabled`

### 圆角

- 小控件：4–6px
- 输入框 / 常规按钮：8px
- 面板 / 小卡片：10–14px
- 大 Banner / 大卡片：18px

### 阴影

优先使用 `--shadow-xs/sm/md/lg`。编辑器里避免大面积强阴影，只在浮层、设备预览和 Hover 提升层级时使用。

## 3. 字体与信息层级

默认字体：`Inter + 系统字体 + PingFang SC + Microsoft YaHei`。

推荐字号：

- 10px：极弱辅助信息、标签
- 11px：次级按钮、面板辅助文字
- 12px：表单、属性项、页面管理
- 13px：常规正文、操作按钮
- 16px：编辑器页标题、一级卡片标题
- 20px+：独立页面主标题

不要使用过重的大标题。B 端界面优先 600–700 font-weight。

## 4. 编辑器布局规范

编辑器固定结构：

`顶部全局导航 → 编辑工具栏 → 左侧组件库 → 左侧页面管理 → 中央画布 → 右侧属性面板`

关键约束：

- 页面管理始终位于中央画布左侧
- 页面管理与组件库视觉分层明显，但都属于左侧操作区
- 手机操作条位于设备右侧，不覆盖 H5 内容
- 属性面板保持固定右侧，不跟随画布缩放
- 画布缩放只影响设备预览，不改变其他面板尺寸

## 5. 页面管理交互

页面卡片支持：

- 单击：切换页面
- 双击页面名称/卡片：重命名
- Hover：显示页面操作栏
- 上移 / 下移：改变页面顺序
- 复制：复制当前页面全部 Schema
- 删除：二次确认；项目至少保留一个页面
- 新增：创建空白页面并自动切换

状态规范：

- Default：透明背景
- Hover：浅蓝灰背景 + 轻边框
- Active：品牌蓝描边 + 浅蓝背景
- Disabled：透明度降低且禁止点击

## 6. 组件选中与画布交互

组件状态：

- Hover：1px 品牌蓝虚线
- Selected：2px 品牌蓝实线 + 8 个控制点
- Dragging：轻透明 + 阴影，不做过大旋转

组件选中后，手机右侧显示纵向操作条：

- 删除
- 上移
- 下移

操作条规则：

- 未选中组件时隐藏
- 第一项时“上移”禁用
- 最后一项时“下移”禁用
- 删除使用危险色 Hover
- 操作后保持当前选中状态，删除除外

## 7. 模板中心规范

模板卡片至少提供：

- 封面
- 模板名称
- 简介
- 标签
- 收藏状态
- 预览
- 使用模板

交互：

- Hover：卡片上浮 2–4px，并显示操作层
- 点击预览：弹出大尺寸模板预览，不立即覆盖当前编辑内容
- 使用模板：明确提示将应用模板，然后进入编辑器
- 收藏：即时反馈，并在“我的收藏”中可过滤
- 自定义模板：允许删除，删除必须确认

模板筛选区至少包括：分类、搜索、推荐 / 收藏 / 我的模板筛选。

## 8. 弹层规范

- 普通确认弹层：420–520px
- 复杂业务弹层：560–680px
- 圆角：12–16px
- Header / Body / Footer 分区明确
- 遮罩不要过深，优先 `rgba(20, 32, 48, .38)` 左右
- 主按钮靠右，取消按钮在主按钮左侧
- 危险操作主按钮必须使用危险色

弹层打开和关闭优先 160–220ms 动画，避免复杂弹跳动画。

## 9. Hover / Focus / Disabled

所有可点击元素必须至少有 Hover 状态。

- Hover：优先调整背景和文字色，不大幅缩放
- Active / Pressed：可使用 0.98–0.99 scale
- Focus：表单使用品牌描边，不依赖浏览器默认 outline
- Disabled：opacity 0.28–0.45，同时 `cursor: not-allowed`

## 10. 响应式

当前编辑器以桌面为主：

- >= 1440px：完整布局
- 1280–1439px：压缩页面管理、组件面板和操作条宽度
- < 1280px：当前版本提示使用桌面端，不强行塞入完整编辑器
- 高度不足时：优先让画布滚动，设备缩放不应导致工具栏或右侧面板被裁切

独立后台页面应支持 1024px 左右的正常展示，卡片网格按 4 → 3 → 2 列降级。

## 11. 开发要求

新增 UI 前检查：

- 是否已有可复用组件或 Token
- 是否与设计稿结构一致
- 是否补齐 Hover / Selected / Disabled / Loading / Empty
- 是否考虑 1440px 和低高度视口
- 是否会造成画布缩放、滚动或弹层层级问题

提交前至少执行：

```bash
pnpm build
```

若修改编辑器主界面，额外检查：页面管理、设备缩放、组件选中、拖拽排序、属性面板、预览和发布流程。
