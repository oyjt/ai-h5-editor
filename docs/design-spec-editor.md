# 营销编辑器主页面视觉规格

> 适用范围：当前营销编辑器主页面。设计稿未覆盖的新页面不在本规格内。

## 1. 整体布局

- 顶部全局导航：62px
- 二级编辑工具栏：64px
- 左侧：一级 Rail + 组件库
- 中间：标尺 + 点阵画布 + 设备预览 + 页面缩略图
- 右侧：属性面板
- 页面背景：浅灰蓝 `#F5F8FC`
- 主色：`#1769FF`
- 常规边框：`#E7EDF4` / `#EDF1F6`

## 2. 组件选中态

- 选中描边：2px `#2684FF`
- 8 个白底蓝边控制点：8px
- 顶部操作条：30px 高，蓝底白图标
- Hover：1px 蓝色虚线，不添加大面积蓝色背景
- 拖拽手柄：左侧轻量悬浮，只在 Hover/Selected 出现

## 3. 设备预览

### 手机

- 设计尺寸：350 × 742
- 外框圆角：44px
- 屏幕圆角：36px
- Dynamic Island：108 × 27

### 平板

- 设计尺寸：430 × 720
- 外框圆角：30px
- 屏幕圆角：24px

### 缩放

- 50%–150%
- 10% 步长
- 缩放只作用于设备预览，不改变编辑器侧栏尺寸

## 4. 营销页面模块

- Banner：首屏主视觉，宽度 100%，在设备内无额外大间距
- 优惠券：粉红渐变容器，3 张券 + 领取按钮
- 商品推荐：双列卡片，图片区域优先，文字两级，价格红色强调
- 报名表单：淡蓝渐变背景，双输入框，蓝色圆角提交按钮
- Tabbar：白底、顶部细分割线、选中项品牌蓝

## 5. 属性面板

- 顶部四 Tab：内容 / 样式 / 交互 / 数据
- 图片组件选中后优先展示图片设置和链接设置
- 图片预览：84 × 57
- 表单控件高度：29px
- 内容区字号以 10–12px 为主
- 高级内容继续复用 Schema 属性编辑能力

## 6. 实现约束

- 不用纯静态截图替代真实编辑能力。
- 所有设计稿中的可操作控件优先连接真实状态。
- 新功能若设计稿未覆盖，先补设计稿再开发。
