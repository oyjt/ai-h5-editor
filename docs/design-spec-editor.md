# 营销编辑器主页面视觉规格

> 适用范围：当前营销编辑器主页面及其直接交互。设计稿未覆盖的新页面，继续遵循“先设计、后开发”。

## 1. 整体布局

- 顶部全局导航：64px
- 二级编辑工具栏：64px
- 左侧：一级 Rail + 组件库 + 页面管理
- 中间：标尺 + 点阵画布 + 手机设备预览
- 右侧：属性面板
- 页面背景：浅灰蓝工作区
- 主色：`--brand-600`
- 常规边框：`--border-subtle` / `--border-default`

## 2. 组件选中态

- 选中描边：2px 品牌蓝
- 8 个白底蓝边控制点：8px
- 手机右侧操作条：删除 / 上移 / 下移
- Hover：1px 蓝色虚线，不添加大面积蓝色背景
- 第一项时上移禁用，最后一项时下移禁用

## 3. 设备预览

### 手机

- 使用统一黑色设备外框
- 顶部刘海 / 听筒 / 摄像头细节与设计稿一致
- 设备内页面保持真实 H5 滚动

### 平板

- 保留平板预览模式
- 不改变左右侧栏宽度

### 缩放

- 50%–150%
- 10% 步长
- 缩放只作用于设备预览，不改变编辑器侧栏尺寸

## 4. 营销页面模块

- Banner：首屏主视觉，宽度 100%
- 优惠券：粉红渐变容器，券卡 + 领取状态
- 商品推荐：双列卡片，图片优先，价格突出，可加购
- 报名表单：淡蓝渐变背景，姓名 / 手机号输入、校验、提交反馈
- 秒杀：真实倒计时与结束状态
- 拼团：参团反馈状态
- 抽奖：剩余次数、抽奖中、结果反馈
- Tabbar：白底、顶部细分割线、选中项品牌蓝

## 5. 属性面板

- 顶部四 Tab：内容 / 样式 / 交互 / 动画
- 图片组件选中后优先展示图片设置和链接设置
- 设置区支持折叠 / 展开
- 控件统一使用 Design Token
- 高级内容继续复用 Schema 属性编辑能力
- 删除组件使用统一危险确认弹层

## 6. 信息架构

当前产品只保留：

- 工作台
- 模板中心
- 我的作品
- 素材管理
- H5 编辑器
- 独立预览 / 发布
- 登录

明确不包含：

- 数据分析
- 团队协作

任何新增一级模块必须先补完整设计稿，再进入开发。

## 7. 实现约束

- 不用纯静态截图替代真实编辑能力。
- 所有设计稿中的可操作控件优先连接真实状态。
- 新功能若设计稿未覆盖，先补设计稿再开发。
- 不允许重新引入数据分析或团队协作入口，除非产品范围重新确认。
